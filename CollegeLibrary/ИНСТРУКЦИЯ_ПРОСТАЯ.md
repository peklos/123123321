# ПРОСТАЯ БИБЛИОТЕКА - ПОШАГОВАЯ ИНСТРУКЦИЯ

## ШАГ 1: Создаём проект

1. Открываем **Visual Studio**
2. Нажимаем **"Создать проект"** (или Файл → Создать → Проект)
3. В поиске пишем **"Windows Forms"**
4. Выбираем **"Приложение Windows Forms"** (C#)
5. Нажимаем **Далее**
6. Пишем имя проекта: **CollegeLibrary**
7. Нажимаем **Создать**

**Что получили:** Открылась пустая форма (окно) и файл Form1.cs

---

## ШАГ 2: Открываем код формы

1. В **Обозревателе решений** (справа) находим **Form1.cs**
2. Нажимаем правой кнопкой → **Перейти к коду** (или F7)
3. Открылся код формы

## ШАГ 4: Пишем весь код (копируй это в Form1.cs)

**Удали всё что есть** в Form1.cs и вставь:

```csharp
using System;
using System.Collections.Generic;
using System.Drawing;
using System.IO;
using System.Text.Json;
using System.Windows.Forms;

namespace CollegeLibrary
{
    public partial class Form1 : Form
    {
        // Список книг
        private List<string> books = new List<string>();
        private string fileName = "books.json";

        // Элементы формы
        private TextBox txtBook;
        private Button btnAdd;
        private Button btnDelete;
        private ListBox listBooks;

        public Form1()
        {
            InitializeComponent();
            CreateElements();
            LoadData();
        }

        // Создаём элементы
        private void CreateElements()
        {
            this.Text = "Библиотека";
            this.Size = new Size(400, 350);

            // Поле ввода
            txtBook = new TextBox();
            txtBook.Location = new Point(10, 10);
            txtBook.Size = new Size(250, 25);
            this.Controls.Add(txtBook);

            // Кнопка Добавить
            btnAdd = new Button();
            btnAdd.Text = "Добавить";
            btnAdd.Location = new Point(270, 10);
            btnAdd.Click += BtnAdd_Click;
            this.Controls.Add(btnAdd);

            // Кнопка Удалить
            btnDelete = new Button();
            btnDelete.Text = "Удалить";
            btnDelete.Location = new Point(270, 45);
            btnDelete.Click += BtnDelete_Click;
            this.Controls.Add(btnDelete);

            // Список
            listBooks = new ListBox();
            listBooks.Location = new Point(10, 45);
            listBooks.Size = new Size(250, 250);
            this.Controls.Add(listBooks);
        }

        // Загрузить из файла
        private void LoadData()
        {
            if (File.Exists(fileName))
            {
                string json = File.ReadAllText(fileName);
                books = JsonSerializer.Deserialize<List<string>>(json);
            }
            UpdateList();
        }

        // Сохранить в файл
        private void SaveData()
        {
            string json = JsonSerializer.Serialize(books);
            File.WriteAllText(fileName, json);
        }

        // Обновить список
        private void UpdateList()
        {
            listBooks.Items.Clear();
            foreach (string book in books)
            {
                listBooks.Items.Add(book);
            }
        }

        // Кнопка Добавить
        private void BtnAdd_Click(object sender, EventArgs e)
        {
            if (txtBook.Text != "")
            {
                books.Add(txtBook.Text);
                SaveData();
                UpdateList();
                txtBook.Text = "";
            }
        }

        // Кнопка Удалить
        private void BtnDelete_Click(object sender, EventArgs e)
        {
            if (listBooks.SelectedIndex >= 0)
            {
                books.RemoveAt(listBooks.SelectedIndex);
                SaveData();
                UpdateList();
            }
        }
    }
}
```

# ОБЪЯСНЕНИЕ КОДА (для понимания)

## Что такое List?
```csharp
List<string> books = new List<string>();
```
Это список строк. Туда можно добавлять книги:
- `books.Add("Война и мир")` - добавить
- `books.RemoveAt(0)` - удалить первую
- `books[0]` - получить первую

---

## Как создать TextBox (поле ввода)?
```csharp
TextBox txtBook = new TextBox();        // создали
txtBook.Location = new Point(10, 10);   // позиция (x, y)
txtBook.Size = new Size(250, 25);       // размер (ширина, высота)
this.Controls.Add(txtBook);             // добавили на форму
```

---

## Как создать Button (кнопку)?
```csharp
Button btnAdd = new Button();           // создали
btnAdd.Text = "Добавить";               // текст на кнопке
btnAdd.Location = new Point(270, 10);   // позиция
btnAdd.Click += BtnAdd_Click;           // что делать при нажатии
this.Controls.Add(btnAdd);              // добавили на форму
```

---

## Как создать ListBox (список)?
```csharp
ListBox listBooks = new ListBox();      // создали
listBooks.Location = new Point(10, 45); // позиция
listBooks.Size = new Size(250, 250);    // размер
this.Controls.Add(listBooks);           // добавили на форму

// Добавить элемент в список:
listBooks.Items.Add("Книга");

// Очистить список:
listBooks.Items.Clear();

// Какой элемент выбран:
int index = listBooks.SelectedIndex;  // -1 если ничего не выбрано
```

---

## Как работает JSON (сохранение)?

**Сохранить список в файл:**
```csharp
string json = JsonSerializer.Serialize(books);  // список → текст
File.WriteAllText("books.json", json);          // текст → файл
```

**Загрузить список из файла:**
```csharp
string json = File.ReadAllText("books.json");   // файл → текст
books = JsonSerializer.Deserialize<List<string>>(json);  // текст → список
```

# ШПАРГАЛКА НА ЭКЗАМЕН

## Using-и (всегда пиши эти):
```csharp
using System;
using System.Collections.Generic;
using System.Drawing;
using System.IO;
using System.Text.Json;
using System.Windows.Forms;
```

## Создать элемент:
```csharp
ТипЭлемента имя = new ТипЭлемента();
имя.Location = new Point(X, Y);
имя.Size = new Size(Ширина, Высота);
this.Controls.Add(имя);
```

## Типы элементов:
- `TextBox` - поле ввода
- `Button` - кнопка
- `Label` - надпись
- `ListBox` - список
- `CheckBox` - галочка

## Обработчик кнопки:
```csharp
btnName.Click += BtnName_Click;

private void BtnName_Click(object sender, EventArgs e)
{
    // код при нажатии
}
```

## JSON:
```csharp
// Сохранить:
File.WriteAllText("file.json", JsonSerializer.Serialize(list));

// Загрузить:
list = JsonSerializer.Deserialize<List<string>>(File.ReadAllText("file.json"));
```

## MessageBox (показать сообщение):
```csharp
MessageBox.Show("Привет!");
```

# УДАЧИ НА ЭКЗАМЕНЕ!

Запомни главное:
1. Создаёшь элемент через `new`
2. Указываешь `Location` и `Size`
3. Добавляешь на форму `this.Controls.Add()`
4. Для кнопки делаешь `Click += метод`
5. JSON: `Serialize` = сохранить, `Deserialize` = загрузить
